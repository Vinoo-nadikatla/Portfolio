# Vinoothna Nadikatla — Portfolio

Personal portfolio site (AI Engineer).

## Deploy on GitHub Pages
1. Create a new repository and upload **all files in this folder** (keep the folder structure — `editorial/` and `assets/` must stay as subfolders next to `index.html`).
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute.

## Files
- `index.html` — the site
- `editorial/` — components (JSX) + helpers
- `assets/` — certificate & research images
- `Vinoothna-Nadikatla-Resume.pdf` — résumé (linked from the site)
- `.image-slots.state.json` — stores the headshot photo so it persists
